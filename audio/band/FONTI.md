# Suoni degli strumenti: fonti e licenze

Tutti i file `.mp3` di questa cartella sono campioni registrati di strumenti
veri, con licenza **CC0 1.0** (pubblico dominio: uso libero, anche commerciale,
senza obbligo di citazione). Li citiamo lo stesso per correttezza.

I file sono stati accorciati, sfumati, portati in mono e convertiti in MP3
per tenerli leggeri (circa 0,5 MB in tutto).

- Fonte: **VSCO 2 Community Edition** di Versilian Studios
- Repository: https://github.com/sgossner/VSCO-2-CE (commit `6dd651d55dde97fd4028699be9d4481f26917891`)
- Licenza: CC0 1.0 Universal (file `LICENSE` del repository)
- File originali usati:
  - Tromba: `Brass/Trumpet/sus/Sum_SHTrumpet_sus_{A#3,D4,F4,A4}_v3_rr1.wav`
  - Contrabbasso: `Strings/Solo Contrabass/Pizz/BKCtbss_Pizz_{E0,G0,A#0,C1,D1,E1,F#1,G#1,C#2}_*_rr1.wav`

    `Percussion/Snare2-HitNS_v3_rr1_Sum.wav`, `Percussion/susCymb1-hitstick_mp_rr1.wav`

- Repository: https://github.com/sfzinstruments/karoryfer.black-and-green-guitars (commit `b3b3249d37dc977a1a297bd2dc053e6d9b6b805c`)
- Licenza: CC0 1.0 Universal (file `LICENSE` del repository; il readme aggiunge
  "Royalty-free for all commercial and non-commercial use")
- File originali usati: `Samples/green/ord/twang_{e3,g3,b3,d4,e4,gb4,g4,a4,b4,c5,e5}_mf_rr1.wav`

Nota: i nomi delle note nei file originali usano la convenzione "Do centrale = C3";
l'intonazione reale di ogni campione è stata misurata ed è scritta in `index.html`
(`SAMPLE_MAP`).
